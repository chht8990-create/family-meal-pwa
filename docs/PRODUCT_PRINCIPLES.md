# HomeOS Product Principles v1.0

## P-01 Family First

모든 기능은 가족의 식사를 더 편리하게 만들어야 한다.

## P-02 AI Optional

AI는 입력·추천·정리를 빠르게 만드는 선택 기능이다.  
핵심 사용 흐름은 AI 없이도 100% 동작해야 한다.

## P-03 One Flow

식단, 레시피, 조리, 재고, 장보기와 식비는 서로 단절된 메뉴가 아니라 하나의 흐름으로 연결된다.

## P-04 Quiet Helper

HomeOS는 자신을 자랑하거나 사용자를 통제하지 않는다.

사용 금지 예시:

- “HomeOS가 결정을 대신했습니다.”
- “AI가 8개의 문제를 해결했습니다.”
- “오늘 목표를 달성하지 못했습니다.”

권장 예시:

- “오늘 장볼 것은 3가지예요.”
- “돼지고기를 냉장실로 옮겨두면 저녁 준비가 편해요.”
- “오늘은 외식으로 표시할까요?”

## P-05 Real Life

계획대로 먹지 않는 날을 예외로 취급하지 않는다.

- 외식
- 배달
- 간편식
- 도시락
- 식사 건너뛰기
- 메뉴 변경

모두 정상적인 생활 상태다.

## P-06 Quality First

기능 개수보다 정확성, 콘텐츠 품질, 사용 편의성을 우선한다.

레시피는 실제 조리가 가능한 수준이어야 한다.

## P-07 Simple Wins

복잡한 완벽함보다 단순하고 지속 가능한 편리함을 선택한다.

## P-08 Progressive Disclosure

처음에는 꼭 필요한 정보만 보여주고, 추가 정보는 사용자가 원할 때 펼쳐서 보여준다.

## P-09 One Screen, One Purpose

- 오늘: 오늘 해야 할 일 확인
- 레시피: 요리하기
- 장보기: 구매하기
- 우리집: 보유 식재료 확인
- 식단: 앞으로 먹을 메뉴 확인·변경

한 화면이 여러 목적을 동시에 수행하지 않도록 한다.

## P-10 Scope Control

좋은 아이디어라도 MVP의 핵심 흐름을 복잡하게 만들면 즉시 구현하지 않고 Backlog로 이동한다.

모든 신규 기능은 다음 질문을 통과해야 한다.

1. 반복되는 실제 문제를 해결하는가?
2. 현재 핵심 흐름을 더 단순하게 만드는가?
3. 새로운 버튼이나 설정을 반드시 추가해야 하는가?
4. 기존 Rule과 충돌하지 않는가?
5. MVP에 지금 필요한가?
