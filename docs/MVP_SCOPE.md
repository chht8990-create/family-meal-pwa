# HomeOS MVP Scope v0.1

## MVP 목표

6인 가족을 포함한 일반 가정이 30일 동안 식단, 레시피, 장보기와 기본 재고 관리를 실제로 사용할 수 있게 한다.

---

## Must Have

### 오늘

- 아침·점심·저녁 표시
- 레시피 보기
- 조리 시작/완료
- 오늘은 안 먹어요
- 외식·배달·간편식·건너뛰기
- 내일 준비 안내

### 식단

- 30일 식단 보기
- 메뉴 변경
- 식사별 상태 표시
- 템플릿 불러오기
- JSON 가져오기/내보내기

### 레시피

- 가족 인원 자동 환산
- 상세 재료
- 사전 준비
- 단계별 조리법
- 불 세기와 시간
- 실패 방지 팁
- 보관법
- 조리 모드

### 장보기

- 식단 기준 자동 산출
- 재고를 제외한 부족 수량 계산
- 수동 추가
- 구매 체크
- 구매 완료 시 재고 반영

### 우리집 식재료

- 품목·수량·단위
- 수동 증가/감소
- 최소 수량
- 선택적 유통기한
- 부족 품목 표시

### 기본 운영

- 로컬 저장
- 새로고침 후 상태 유지
- 백업/복원
- 오프라인 사용
- 모바일 우선

---

## Should Have

- 기본 식비 예산
- 구매 가격 기록
- 유통기한 임박 안내
- 메뉴별 즐겨찾기
- 우리집 기본 장바구니
- 공식 추천 식단
- 준탱 추천 식단

---

## Not in MVP

- 냉장고 사진 인식
- 영수증 OCR
- 실시간 가족 동기화
- 커뮤니티 게시판
- 식재료 가격 자동 비교
- 날씨 기반 자동 메뉴 변경
- 건강 진단·의료 영양 추천
- AI 자동 실행
- 음성 비서
- 스마트 가전 연동

제외 기능은 폐기하지 않고 Feature Backlog에서 관리한다.
