# WS-05 — Cooking Mode v1.0

## 1. 목적

Cooking Mode는 사용자가 요리하는 동안 휴대폰을 옆에 두고 한 단계씩 따라갈 수 있도록 하는 전용 실행 화면이다.

핵심 목표:

- 한 화면에 한 단계
- 다음 행동이 즉시 이해됨
- 불 세기와 시간 명확
- 타이머를 놓치지 않음
- 손이 젖은 상황에서도 조작 가능
- 조리 완료 시 재고 차감과 상태 변경이 안전하게 연결됨

---

## 2. 핵심 원칙

### One Step, One Screen

한 화면에는 현재 단계 하나만 표시한다.

### Large Touch Targets

주요 버튼은 최소 48px 이상 터치 영역을 사용한다.

### Low Cognitive Load

사용자는 현재 해야 할 행동과 완료 판단 기준만 보면 된다.

### No Hidden Completion

마지막 단계가 끝났다고 자동으로 조리 완료 처리하지 않는다.
사용자의 명시적 확인이 필요하다.

### Timer Is Optional

타이머가 있어도 사용자가 원치 않으면 시작하지 않을 수 있다.

### Keep Screen Awake, But Respect Battery

조리 모드 진행 중에만 화면 꺼짐 방지를 요청한다.
앱을 벗어나거나 조리 모드를 종료하면 해제한다.

### Safe Exit

뒤로가기나 앱 종료 시 진행 위치를 저장한다.

---

## 3. 화면 구성

상단:

- 메뉴명
- 현재 단계 / 전체 단계
- 나가기

중앙:

- 단계 제목
- 행동 설명
- 불 세기
- 예상 시간
- 완료 판단 기준

하단:

- 이전
- 타이머
- 다음 또는 조리 완료

---

## 4. 상태 연결

조리 모드 시작:

MealPlan planned → cooking

조리 모드 일시 중단:

MealPlan은 cooking 유지
현재 단계 저장

조리 모드 종료 전:

사용자에게 다음을 확인한다.

- 조리가 끝났는지
- 재고 차감 예정인지

확인 후:

MealPlan cooking → cooked
WS-04 InventoryConsumed 실행
