# HomeOS Core UX Flow v0.1

## 1. 하단 메뉴

- 오늘
- 식단
- 장보기
- 우리집
- 더보기

레시피는 독립적인 최상위 탭이 아니라 오늘·식단·검색 결과에서 진입한다.

---

## 2. 오늘 화면

목적: 사용자가 3초 안에 다음 행동을 결정한다.

구성 순서:

1. 필요한 사전 준비
2. 아침
3. 점심
4. 저녁
5. 오늘 장보기
6. 유통기한 안내
7. 이번 달 식비 요약

식사 카드의 기본 버튼:

- 레시피
- 조리 시작 또는 조리 완료
- 더보기

`더보기` 안에:

- 오늘은 안 먹어요
- 메뉴 변경
- 날짜 이동

홈 화면에 외식·배달·건너뛰기 버튼을 모두 직접 노출하지 않는다.

---

## 3. 오늘은 안 먹어요 흐름

오늘 식사 카드  
→ 더보기  
→ 오늘은 안 먹어요  
→ 선택

- 외식
- 배달
- 간편식
- 도시락
- 건너뛰기

선택 후 필요할 때만 비용 입력을 제안한다.

완료 문구 예:

- “외식으로 표시했어요.”
- “오늘 점심은 건너뛴 것으로 표시했어요.”

금지 문구:

- “계획을 지키지 못했습니다.”
- “식단 성공률이 낮아졌습니다.”

---

## 4. 레시피 흐름

오늘 식사 카드  
→ 레시피  
→ 요약

기본 표시:

- 조리시간
- 난이도
- 인원
- 재료
- 조리 순서

펼쳐보기:

- 사전 준비
- 실패 방지 팁
- 대체 재료
- 보관법
- 곁들임

주요 버튼:

- 조리 모드 시작
- 부족한 재료 장보기에 추가

---

## 5. 조리 모드

한 화면에 한 단계만 표시한다.

- 현재 단계
- 해야 할 행동
- 예상 시간
- 불 세기
- 이전 / 다음
- 타이머 시작
- 조리 종료

조리 종료 전에 재고 차감 예정 내용을 간단히 확인시킨다.

---

## 6. 장보기 흐름

장보기  
→ 품목 체크  
→ 구매 완료  
→ 수량 확인  
→ 재고 반영

가격 입력은 건너뛸 수 있다.

---

## 7. 복잡도 제한

- 한 화면의 주 행동은 1개
- 주요 버튼 최대 3개
- 설정이 필요한 기능은 기본값 제공
- 사용 빈도가 낮은 기능은 더보기 안에 배치
- 모달을 연속해서 두 번 이상 띄우지 않음
