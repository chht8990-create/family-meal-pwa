# WS-02 Prototype Recipe Migration Plan

## 1. 현재 문제

기존 프로토타입 레시피는 다음 문제가 있다.

- 화면 표시용 문자열 중심
- 재료 식별자가 일관되지 않음
- 재료와 양념 구조가 분리되지 않거나 제각각임
- 인원 환산 규칙이 단순 비례
- 단계별 불 세기·시간이 구조화되지 않음
- 재고 차감과 레시피 표시 데이터가 직접 결합됨

## 2. 마이그레이션 순서

1. 기존 레시피 목록 추출
2. 이름 기준으로 recipeId 생성
3. ingredientId 정규화
4. 기준 인원 확정
5. 재료를 IngredientLine으로 변환
6. scaling mode 지정
7. 준비·조리 단계 구조화
8. 품질 체크리스트 검증
9. 기존 MealPlan의 recipe 참조 교체
10. 조리 완료 재고 차감 회귀 검증

## 3. 호환 계층

마이그레이션 중에는 기존 필드를 읽는 adapter를 둘 수 있다.

단, 새 레시피 저장은 새 schema만 허용한다.

## 4. 실패 방지

- 기존 localStorage를 바로 삭제하지 않는다.
- 최초 실행 시 백업본을 생성한다.
- 변환 실패 레시피는 원본과 함께 격리한다.
- 재고 차감은 새 schema 검증에 성공한 레시피만 허용한다.
