# WS-03 UX Flow v1.0

## 1. 식사 카드 기본 화면

- 메뉴명
- 상태
- 레시피
- 조리 시작 또는 조리 완료
- 더보기

주요 버튼은 최대 3개를 유지한다.

---

## 2. 더보기

- 오늘은 안 먹어요
- 메뉴 변경
- 기록 수정
- 다른 날짜로 이동

---

## 3. 오늘은 안 먹어요

식사 카드  
→ 더보기  
→ 오늘은 안 먹어요  
→ 선택

- 외식
- 배달
- 간편식
- 도시락
- 건너뛰기

선택 후 완료 메시지와 실행 취소를 표시한다.

---

## 4. 메뉴 변경

식사 카드  
→ 더보기  
→ 메뉴 변경  
→ 최근 메뉴 또는 검색  
→ 변경 결과 확인  
→ 적용

확인 화면:

- 기존 메뉴
- 새 메뉴
- 새로 필요한 재료 수
- 장보기 반영 여부

---

## 5. 조리 완료

조리 완료  
→ 재고 차감 예정 간단 확인  
→ 완료  
→ 상태 변경 및 재고 차감  
→ 실행 취소 10초

한 번 완료된 버튼은 비활성화한다.

---

## 6. 문구 원칙

사용:

- 외식으로 표시했어요.
- 오늘 저녁 메뉴를 변경했어요.
- 조리 완료로 표시했어요.
- 실행 취소했어요.

금지:

- 계획을 지키지 못했어요.
- 식단 성공률이 떨어졌어요.
- 오늘 목표에 실패했어요.
- HomeOS가 대신 결정했어요.
