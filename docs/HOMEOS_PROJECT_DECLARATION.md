# HomeOS Project Declaration v1.2

## 1. 프로젝트 정의

HomeOS는 **가정의 식사를 가장 쉽고 편리하게 만들어 주는 생활형 식사 관리 플랫폼**이다.

HomeOS는 사용자를 대신해 생활을 통제하거나 가정을 운영하려는 제품이 아니다.  
오늘의 식사, 레시피, 장보기, 식재료 재고와 식비 흐름을 자연스럽게 연결하여 가족이 식사 준비에 쓰는 시간과 고민을 줄이는 것이 목적이다.

내부적으로 `Home Operating System`이라는 구조적 비전을 유지하되, 사용자에게는 다음 가치로 설명한다.

> **오늘의 식사를 가장 쉽고 편리하게.**

보조 설명:

> 식단 · 레시피 · 장보기 · 식재료 · 식비를 한 곳에서

---

## 2. 제품이 해결하는 문제

가정에서는 매일 다음과 같은 작은 불편이 반복된다.

- 오늘 무엇을 먹을지 결정하기 어렵다.
- 레시피를 별도로 검색해야 한다.
- 집에 어떤 재료가 있는지 기억하기 어렵다.
- 필요한 장보기 품목을 빠뜨린다.
- 남은 재료를 버리게 된다.
- 가족 인원에 맞는 재료량 계산이 번거롭다.
- 외식·배달 등 현실적인 변경 때문에 식단 계획이 쉽게 무너진다.

HomeOS는 각각의 문제를 별도 기능으로 흩어 놓지 않고 하나의 생활 흐름으로 연결한다.

---

## 3. 핵심 생활 흐름

식단 확인  
→ 레시피 확인  
→ 조리  
→ 조리 완료  
→ 식재료 차감  
→ 부족 재료 판단  
→ 장보기 반영  
→ 구매 완료  
→ 재고 증가  
→ 식비 반영

사용자가 모든 과정을 직접 기록하도록 요구하지 않는다.  
필요한 순간에 최소한의 행동만 요청하고 나머지는 조용히 연결한다.

---

## 4. 사용자에게 약속하는 것

1. AI가 없어도 완전하게 사용할 수 있다.
2. 처음 사용하는 사람도 설명서 없이 사용할 수 있다.
3. 식단이 계획대로 진행되지 않아도 불이익을 주지 않는다.
4. 외식·배달·간편식·건너뛰기 같은 현실적인 선택을 자연스럽게 지원한다.
5. 사용자의 생활을 평가하거나 통제하는 문구를 사용하지 않는다.
6. 기능 수보다 매일 쓰기 편한 완성도를 우선한다.

---

## 5. MVP 성공 기준

> 한 가족이 한 달 동안 HomeOS만으로 식단, 레시피, 장보기와 기본 식재료 관리를 무리 없이 계속 사용할 수 있는가?

이 질문에 실제 사용자가 “그렇다”고 답할 때 MVP를 완료한다.
