# HomeOS Blueprint v0.1

## 1. 제품 정의

HomeOS는 AI 없이도 완전하게 사용할 수 있고, AI를 선택적으로 활용할 수 있는 가정 식단·장보기·재고·식비 운영 앱이다.

## 2. 고정 원칙

- Family First: 부모님도 설명 없이 사용할 수 있어야 한다.
- AI Optional: 식단, 장보기, 재고, 예산, 레시피는 AI 없이 작동한다.
- Offline First: 핵심 기능은 인터넷 없이 사용할 수 있다.
- No Waste: 전달 재고를 이월하고 남은 재료를 우선 사용한다.
- Real Life: 통계보다 오늘 해야 할 행동을 먼저 보여준다.
- Balanced by Default: 첫 설치부터 균형식 기본 템플릿을 제공한다.

## 3. 홈 화면 핵심 흐름

1. 오늘 점심·저녁 메뉴 확인
2. 메뉴별 `레시피 보기`
3. 인원수 기준 재료량과 조리 순서 확인
4. `조리 완료` 선택
5. 사용 재료 재고 차감
6. 부족 재료와 장보기 수량 갱신

## 4. 홈 화면 정보 우선순위

- 오늘의 점심과 저녁
- 메뉴별 레시피 보기
- 메뉴별 조리 완료
- 남은 장보기 품목 수
- 부족 재고
- 이번 달 남은 예산
- 내일 준비할 재료

## 5. 기본 제공 콘텐츠

- 균형식 일반형 30일
- 균형식 절약형 30일
- 균형식 간편형 30일
- 실제 사용 검증형 `준탱 추천 식단`

## 6. AI 미사용자를 위한 간접 AI 활용

AI가 생성하고 실제 사용자가 검증한 식단·레시피·장보기 패키지를 앱에서 버튼 한 번으로 적용할 수 있게 한다. 사용자는 AI 계정이나 사용법을 몰라도 AI로 개선된 결과물을 이용한다.

## 7. 초기 비AI 핵심 엔진

- 인원수별 재료량 계산
- 식단 기반 총 필요량 합산
- 기존 재고 차감
- 1차·2차 장보기 분리
- 구매 완료 시 재고 증가
- 조리 완료 시 재고 차감
- 전월 재고 이월
- 월별 예산과 실제 지출
- 레시피 저장·조회
- 균형식 규칙 검사

## 8. AI 확장 경계

AI는 다음 작업을 빠르게 하는 선택 기능이다.

- 자연어 식단 생성·수정
- 영수증 입력 보조
- 냉장고 사진 재고 추정
- 남은 재료 활용 추천
- 예산·행사 기반 대체 메뉴 추천

AI 실패·중단 시에도 사용자가 직접 입력하여 같은 결과를 만들 수 있어야 한다.
