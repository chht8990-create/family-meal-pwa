# WS-00 Decision — Today Home Flow

## 판정

홈 화면은 조회용 대시보드가 아니라 `오늘 해야 할 행동`의 실행 화면으로 정의한다.

## 오늘 식사 카드

각 점심·저녁 카드에는 아래 항목을 제공한다.

- 식사 구분
- 메뉴명
- 예정/완료 상태
- 레시피 보기
- 조리 완료

## 레시피 화면

- 현재 선택한 가족 인원 기준 재료량
- 재료 단위
- 순서형 조리 과정
- 향후 재고 부족 표시와 장보기 추가 버튼 연결

## 조리 완료 처리

- 사용자 확인 후 완료 처리
- 레시피 사용량만큼 재고 차감
- 홈·식단·장보기·재고 화면 즉시 갱신
- 중복 차감 방지

## 추후 보완

- 조리 취소 시 차감 복원 거래
- 실제 사용량 수정
- 일부 재료 제외
- 대체 메뉴 선택
- 조리 시작 타이머
