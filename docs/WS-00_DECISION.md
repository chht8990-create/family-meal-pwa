# WS-00 Decision — Today Home Flow

## 판정

홈 화면은 조회용 대시보드가 아니라 `오늘 해야 할 행동`의 실행 화면으로 정의한다.

## 오늘 식사 카드

각 점심·저녁 카드에는 아래 항목을 제공한다.

- 식사 구분
- 메뉴명
- 예정/완료 상태
- 레시피 보기
- 조리 완료

## 레시피 화면

- 현재 선택한 가족 인원 기준 재료량
- 재료 단위
- 순서형 조리 과정
- 향후 재고 부족 표시와 장보기 추가 버튼 연결

## 조리 완료 처리

- 사용자 확인 후 완료 처리
- 레시피 사용량만큼 재고 차감
- 홈·식단·장보기·재고 화면 즉시 갱신
- 중복 차감 방지

## 추후 보완

- 조리 취소 시 차감 복원 거래
- 실제 사용량 수정
- 일부 재료 제외
- 대체 메뉴 선택
- 조리 시작 타이머

## WS-00D 사용자 검증 반영

- 홈 화면과 월간 식단의 식사 슬롯을 아침·점심·저녁 3식으로 확장한다.
- 레시피는 단순 메모가 아니라 실제 조리에 사용할 수 있는 실행 문서로 제공한다.
- 필수 구성: 예상 시간, 난이도, 메뉴 설명, 정량 재료, 조리 전 준비, 단계별 조리법, 실패 방지 팁, 선택적 곁들이기.
- 인원수 변경 시 재료량은 기존과 동일하게 자동 환산한다.
