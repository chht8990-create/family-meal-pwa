# Cooking Timer Policy v1.0

## 1. 타이머 생성

RecipeStep에서 다음 조건을 만족하면 타이머 버튼을 표시한다.

- minutes > 0
- timerRecommended = true

---

## 2. 타이머 동작

- 시작
- 일시 정지
- 재개
- 종료
- 시간 추가

빠른 추가:

- +30초
- +1분
- +5분

---

## 3. 단계 이동과 타이머

다음 단계로 이동해도 타이머는 계속 실행될 수 있다.

여러 타이머 동시 실행은 MVP에서 최대 3개로 제한한다.

---

## 4. 알림

타이머 종료 시:

- 앱 내부 알림
- 진동
- 소리

사용자가 소리·진동을 끌 수 있다.

운영체제 알림 권한이 없으면 앱 내부에서만 알린다.

---

## 5. 백그라운드

타이머는 wall-clock 기준 종료 시각을 저장한다.

앱이 백그라운드에 있어도 복귀 시 남은 시간을 정확히 계산한다.
단순 interval 누적 방식만 사용하지 않는다.

---

## 6. 자동 단계 이동 금지

타이머가 끝나도 다음 단계로 자동 이동하지 않는다.

안내:

`고기를 확인할 시간이에요.`

사용자가 완료 여부를 판단한다.
