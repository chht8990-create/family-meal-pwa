# HomeOS Undo Policy v1.0

## 1. 목적

실수로 상태를 변경하거나 재고를 차감한 경우 사용자가 즉시 원래 상태로 되돌릴 수 있어야 한다.

---

## 2. 즉시 실행 취소

상태 변경 후 10초 동안 스낵바를 표시한다.

예:

`조리 완료로 표시했어요.  [실행 취소]`

지원 대상:

- 조리 시작
- 조리 완료
- 식사 완료
- 외식
- 배달
- 간편식
- 도시락
- 건너뛰기

---

## 3. 조리 완료 Undo

Undo 시:

- MealPlan 상태를 이전 상태로 복구
- 차감된 재고를 정확히 복구
- 생성된 부족 장보기 항목이 해당 이벤트 때문에 생긴 경우 재계산
- 원본 이벤트는 삭제하지 않고 reversed로 표시
- 반대 이벤트를 추가 기록

---

## 4. 시간이 지난 후 수정

10초가 지난 뒤에는 식사 카드의 `기록 수정`에서 변경한다.

기록 수정은 다음 순서로 처리한다.

1. 현재 상태 영향 확인
2. 사용자에게 변경 결과 안내
3. 재고 또는 비용 역처리
4. 새 상태 적용
5. 수정 이벤트 기록

---

## 5. Undo 제한

다음 경우 자동 Undo를 금지하고 수정 흐름으로 전환한다.

- 해당 재고가 이후 다른 조리에 사용됨
- 가족 동기화 후 다른 기기에서 변경됨
- 구매·폐기 등 후속 이벤트가 연결됨
- 복구하면 재고 무결성이 깨짐

MVP에서는 안내 후 수동 조정 화면으로 이동한다.
