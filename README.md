# HomeOS WS-06B — Monthly Meal Plan & Period Shopping

## 현재 판정

IMPLEMENTED — USER VALIDATION REQUIRED

## 핵심 변경

- 실제 월간 식단 구조
- 홈에는 오늘 식단만 표시
- 식단 탭에서 월 전체 달력 보기
- 이전 달·다음 달 이동
- 날짜별 아침·점심·저녁 확인
- 날짜별 메뉴 변경
- 메뉴 변경 후 장보기 즉시 재계산
- 장보기 범위
  - 오늘
  - 이번 주
  - 다음 7일
  - 이번 달
  - 직접 기간 선택
- 선택 기간 전체 재료 합산
- 현재 재고 차감 후 부족량 계산
- 신선식품과 장기보관 품목 분리
- 구매 완료 후 재고 증가 및 재계산
- 일반 조리 1~6인분
- 7인분 이상 대용량 조리

## 검증 순서

1. 오늘 탭에는 오늘 식단만 표시되는지
2. 식단 탭에서 한 달 전체 달력이 표시되는지
3. 이전 달·다음 달 이동이 가능한지
4. 날짜 선택 시 3끼가 표시되는지
5. 메뉴 변경 후 달력과 장보기가 갱신되는지
6. 장보기 범위별 날짜가 맞는지
7. 다음 7일 장보기와 이번 달 장보기 수량이 달라지는지
8. 신선식품과 장기보관 품목이 분리되는지
9. 구매 완료 후 재고 증가 및 부족량 재계산이 되는지
