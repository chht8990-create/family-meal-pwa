# WS-04 Test Plan

## 부족량 계산

### SH-001

필요량 1200g, 재고 500g  
부족량 700g

### SH-002

필요량 3개, 재고 5개  
장보기 미생성

### SH-003

같은 재료가 여러 레시피에 있으면 합산

### SH-004

cooked, skipped, dining_out 식사는 필요량에서 제외

### SH-005

expired 재고는 사용 가능 수량에서 제외

---

## 단위

### UN-001

kg를 g로 정규화 후 합산

### UN-002

piece와 g는 conversion 없이 합산 금지

### UN-003

판매 단위 600g, 부족량 700g이면 1200g 권장

---

## 병합

### MG-001

동일 ingredientId와 unit의 미구매 항목 병합

### MG-002

구매 완료 항목에는 새 부족량 병합 금지

### MG-003

수동 메모 유지

### MG-004

사용자 수정 구매량 유지

---

## 구매 완료

### PC-001

체크만으로 재고 증가 없음

### PC-002

구매 완료 시 실제 구매량만 재고 증가

### PC-003

가격 미입력 가능

### PC-004

동일 idempotencyKey 중복 구매 완료 거부

### PC-005

구매 완료 후 부족량 재계산

---

## 조리 연동

### CO-001

조리 완료 시 FEFO 순서로 재고 차감

### CO-002

재고 부족 시 실제 보유량까지만 차감

### CO-003

부족 수량 기록

### CO-004

조리 완료 중복 실행 시 중복 차감 없음

---

## Undo

### UD-001

조리 완료 Undo 시 lot 수량 복구

### UD-002

복구 후 부족량 재계산

### UD-003

구매 후 해당 재고가 사용되었으면 자동 구매 Undo 금지
