# Serving Scaling Test Cases

## TC-001 linear

기준 6인, 돼지고기 1200g → 4인  
예상: 800g

## TC-002 gentle

기준 6인, 간장 6큰술 → 4인  
단순 비례보다 조금 많은 값이 나와야 한다.

## TC-003 minimal

기준 6인, 참기름 2큰술 → 10인  
단순 비례값 3.33큰술보다 작아야 한다.

## TC-004 capped

고춧가루 maxQuantity 7큰술  
10인 환산값이 7큰술을 초과하면 안 된다.

## TC-005 discrete

기준 6인, 양파 2개 → 4인  
0.5개 단위 올림 적용.

## TC-006 범위 제한

1인 또는 11인 입력 시 오류.

## TC-007 재고 차감

선택된 인원 기준 환산값과 실제 차감량이 같아야 한다.

## TC-008 중복 완료

같은 MealPlan의 조리 완료를 두 번 실행해도 재고는 한 번만 차감되어야 한다.
